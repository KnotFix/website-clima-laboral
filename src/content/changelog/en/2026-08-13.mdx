  title: "The kiosk QR no longer expires",
};

- **A kiosk station lives until someone closes it.** Closing the tab or turning
  the tablet off used to delete the station, and the device had to be registered
  again with a new QR. A code taped to a wall now still works tomorrow.
- **The QR can be viewed again** from the station's card. It used to be shown
  once, and closing the dialog without copying it left the tablet with no way to
  pair.
- In exchange, **"Delete" is now how you revoke** a station's link: as long as it
  exists, the code works.
- **The header shows where you are**, with the full trail down to the current
  screen.
